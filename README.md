# 简历工坊 · Resume Atelier

中文简历编辑网站。参考杂志式简历的双栏、色块、时间轴与字体层次，提供 11 套模板、4 种布局，所有模板使用可编辑文字而非图片。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。

```sh
npm test
npm run build
npm run preview
```

构建生成的 `dist/` 可部署到静态网站服务。项目没有服务器和账户系统；每位使用者的草稿保存在其当前浏览器中，跨设备使用需要导出并导入 JSON 备份。

## 功能

- 姓名、联系方式、简介、经历、项目、教育、技能和自定义模块；模块增删、隐藏、上下排序及主侧栏调整。
- 11 套独立主题；左侧栏、右侧栏、单栏、三栏；切换模板保留内容。
- 分别选择正文与标题字体；调整字号、字重、字距、行距、模块间距、页边距和主题色。
- 头像上传及方形、圆形、拱形；照片仅在本机处理和存储。
- 实时预览、缩放、专注预览、自动保存、撤销重做、备份导入导出。
- A4 打印样式；超过一页时提示，浏览器负责分页。打印时建议关闭浏览器页眉页脚并开启背景图形；长文最终分页以浏览器打印预览为准。
- 手机端独立编辑、预览和设计视图。

字体优先使用本机字体，界面与宋体可加载 Google Fonts 的 Noto Serif SC，网络不可用时使用系统备用字体。不同设备的字体可用性会影响字形和换行。初始内容为示例，不代表任何真实个人履历。

## 设计参考

- 用户提供的 10 张简历图片：黑金、几何、奶油圆角、亚麻、黑白细线、卡片、时间轴、瑞士三栏、雾蓝、经典商务等风格；未将参考图片及其中人物照片打包进网站。
- [FlowCV](https://flowcv.com/)：内容与设计分离、保留内容切换模板。
- [Canva](https://www.canva.com/create/resumes/)：可视化模板选择、颜色与字体配置。
- [Reactive Resume](https://rxresu.me/)：实时预览与模块化内容。
